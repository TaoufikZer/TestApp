# Montréal Trip Planner

A 14-day Montréal trip planner (Dec 5–18): itinerary, day-by-day timelines, places to explore, budget and packing list.
English or French, light or dark.

- `app/index.html` — the app (no build step; plain HTML, CSS and JS)
- `app/seed.json` — the starting 14-day plan

Run locally:

```bash
cd app && python3 -m http.server 8000
```

Then open http://localhost:8000. Locally, changes are saved in your browser.
